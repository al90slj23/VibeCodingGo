# 0.30.0 工程工具交付记录（2026-10-30）

最终版本 **0.30.0 / build 44** 已安装到 `/Applications/VibeCoding Go.app`。

## 实际功能

新增第四个一级标签「工程工具」，在原有主面板内通过「环境体检 / 接口调试 / 日志诊断」二级标签切换。三页复用一个原生视图和控制器，旧任务提醒、编程助手、网络检测的稳定路由不变。

- 环境体检：固定项目声明文件、实际工具路径与版本、明确/待核对的约束；复用可选 mise 的离线无配置库存接口。含歧义的部分严格版本比较不猜测，工具存在但版本读取失败不显示绿色通过。
- 接口调试：系统 curl 单请求、可选 Hurl 请求集合，真实状态/响应、断言结果、代理、超时、取消与常见敏感字段脱敏；输入只走 stdin，不自动重试/跳转。
- 日志诊断：最多 5 个文件、每文件 512 KiB、合计 2 MiB 的尾读，字面筛选、级别和跨时区排序；可选 lnav 只处理私有脱敏快照，不丢弃原生未识别行，不伪造绝对行号。

开源 CLI 通过动态发现按需执行，不捆绑另一套应用或常驻服务。实际适配验证使用临时官方 mise 2026.10.23、Hurl 8.1.0、lnav 0.14.1，发布资产的 SHA-256 已核对；没有全局安装这些工具。缺少它们时基础环境检查、单请求 HTTP 和有界日志尾读仍可用。

具体操作与边界见[工程工具说明](engineering-tools.md)。

## 响应与资源约束

- 构造、导航、文件选择和恢复可见都不启动采集。工程工作共用独立槽，最大并发 1；不占用聊天/状态保留槽。
- 工具执行无 shell，输入、双管道输出、运行时限有界；取消只清理自身任务和子进程组。工程进程有单独退出兜底，聊天发送的 receipt 规则未改变。
- 报告在后台准备，全 UI 文本限 96 KiB；隐藏/最小化/遮挡回包只缓存。
- 几何身份包含页面、模式、busy、根尺寸和真实滚动视口。100 次相同空闲布局调用不重复写 frame/TextKit 尺寸；真实 resize、模式、报告和滚动条变化仍失效。
- `performance.engineering` 记录运行、取消、布局/几何写入与可见性计数，不写请求或日志内容。没有新增轮询时钟。

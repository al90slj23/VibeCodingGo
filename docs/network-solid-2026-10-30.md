# 网络检测加固与验收：0.32.0

2026-10-30。安装版本 **0.32.0 / build 47**，应用位于 /Applications/VibeCoding Go.app。六项检测继续使用同一主面板下的两级标签，不创建独立功能窗口。本轮未更改 Codex 账号、授权或系统代理配置。

## 修复范围

- **IP 信誉**：归属与风险必须匹配目标 IP；按来源展示六类信号、风险分与覆盖信息。拒绝、限流、未知字段保留未知。风险来源不可用时只以 Tor 官方列表补充 Tor 信号，不伪造综合纯净度。
- **域名检测**：系统 DNS 与 Cloudflare/Google DoH 的 A、AAAA 分别核对，校验 Question、记录类型和可达 CNAME 链。DNS 差异、HTTPS/TLS、HTTP 403/429/500 分开报告，避免把服务拒绝或解析差异当作全网封禁。
- **出口痕迹**：同一路由观察多个出口来源，按 IPv4/IPv6 分组比较；不同协议的地址不同不构成泄露证据。IPv6 失败保持未知。浏览器 WebRTC/DNS 测试仍需手动在实际浏览器运行。
- **全球 Ping**：修正官方探针地区字段解析，逐地区限制一个探针；展示实际节点、ASN、国家、丢包、失败与覆盖不足，不再把有结果但缺少目标国家视为完整。
- **全球 HTTP**：保留来源的目标状态、DNS/TCP/TLS/首字节/总时延；证书明确不可信时保留可达观察，但标为部分结果，不显示绿色完成。
- **轻量测速**：按实际接收字节和时间计算，分别显示整次请求有效速率与正文传输速率；零时长不伪造速率。最多 5 MiB、12 秒，短样本不推断宽带峰值。
- **共同交互**：停止、复制、保留已创建的测量 ID，并只 GET 续查；避免每次刷新重新创建探针。新输入或新运行会使旧结果失效。Retry-After、来源配额与终态明确显示。

## 当前安装版实测

执行的是安装目录 runtime 中的代码，从应用 launchd 环境与当前代理规则发起请求；没有用替代实现绕过系统路径。目标采用 example.com、8.8.8.8 等公共测试目标。下表为当时观察，不保证外部服务永远可用。

| 检测 | 安装版观察 | 用时 |
| --- | --- | --- |
| 域名 | PAC/HTTP 代理路径 HTTPS 200；系统 DNS 和两家公共 DNS 的 A/AAAA 完成 | 2.91 秒 |
| IP 信誉 | ipapi.is 与 proxycheck.io 均返回对应目标；六项风险字段可读 | 1.41 秒 |
| 出口痕迹 | 两个 IPv4 观察一致；IPv6 不可确认，明确保留未知 | 1.87 秒 |
| 全球 Ping | 复用已有测量，仅 GET；美国、德国、新加坡 3/3 | 0.86 秒 |

| 轻量测速 | 完整接收 1 MiB；请求有效速率约 7.70 Mbps、正文传输约 16.91 Mbps，标为短样本 | 1.20 秒 |

IP 信誉测试对象为 8.8.8.8，来源的“匿名网络”等标记属于来源对该测试目标的记录，不能归到用户出口。公网出口地址、代理凭证与私有 DNS 信息未写入本交付记录。

本轮全部探针验证累计使用 10 个 Globalping 探针测试，包括修复前基线与安装版确认；Ping 续查没有新建测量。测速基线和安装版各下载 1 MiB，共 2 MiB，另有小型 API 响应流量。

## 传输、取消与资源边界

生产请求直接使用系统 curl，保留系统证书验证，支持环境和 macOS HTTP/HTTPS/SOCKS/PAC、NO_PROXY、系统例外及已有 TUN 路由。代理失败不会悄悄直连；凭证、敏感头和请求体通过 stdin，响应与错误输出有硬上限。GET/HEAD 不自动跟随目标重定向。304/204 无正文响应与 gzip 展开独立处理，超深 JSON 和畸形数值受控退出。

一次操作默认 45 秒总预算，上限 55 秒；DNS/PAC/子请求共享预算。Stop 终止并回收该操作自己的进程组，原生兜底在一秒后终止忽略 SIGTERM 的诊断进程。隔离端到端测试通过本地悬停代理确认：CLI 收到 SIGTERM 后关闭连接并返回 cancelled，不等待完整网络超时。

页面打开与切换不触发请求，不新增轮询时钟。报告在 utility 队列准备，总文本最多 96 KiB，最多缓存六份。隐藏窗口只缓存结果，显示后由窗口事件应用；无变化不重复 TextKit 布局。工具自动更新在网络检测执行或排队时延期。用量账本和金额统计路径未修改。

## 结果解释与来源

Globalping 会接收并可能公开保留测量目标。全球 HTTP 按来源返回的单次 HTTPS HEAD 状态展示，3xx 不当作跟随后可达。官方探针允许取得证书异常目标的响应，再返回 tls.authorized，因此 HTTP 200 与 TLS 可信必须分开。firstByte 是探针的建连后分段时间；本机 curl 的首字节是请求开始后的累计时间，两者不直接比较。[官方探针实现](https://github.com/jsdelivr/globalping-probe/blob/master/src/command/handlers/http/undici.ts)、[API 契约](https://github.com/jsdelivr/globalping/blob/master/public/v1/spec.yaml)。

单次检测无法保证账号不会被封禁、域名在所有地区可达、真实物理住址绝不泄露或浏览器没有 DNS/WebRTC 泄露。这里保留来源、范围、失败和未知项，让检测结论与实际证据一致。来源额度与隐私说明见[来源研究](network-provider-research.md)。
